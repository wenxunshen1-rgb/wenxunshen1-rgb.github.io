# 中国大陆访问加速：部署与验证指南（2026-11-17）

> 当前网站: https://wenxunshen1-rgb.github.io/ 。本文件只是操作方案；并不表示腾讯云部署、域名绑定或测速已经完成。
> 目标：国内真实网络下首页主要内容（LCP）尽可能 <= 5 秒，非一次性下载所有项目图库。

## 已知现状
- GitHub 仓库规模约 626 MiB；不等于首页传输数据量。
- 45 个项目、21 个额外作品预览，项目详情包含约 1,068 个图片条目；长画廊必须延迟加载。
- HTML、CSS、JS 以静态方式部署，现有 main 分支托管在 GitHub Pages。
- 本分支已把开场视频改为点击后加载，并延迟构建预览滚动区。该版本尚未在国内端到端验证。

## 推荐生产架构
GitHub 同一代码源 -> GitHub Pages（原地址备用）+ 腾讯云 EdgeOne Pages（绑定个人已备案域名，选择中国大陆可用区）。

### 在未备案前
1. 保留 GitHub Pages，不要改 DNS。
2. 购买、实名认证自有域名（例如自选的 .com，不能给 github.io 子域名备案）。
3. 可以先在 EdgeOne Pages 用“全球（不含中国大陆）”区域 + 自定义域名作对照测试；此方案不使用中国大陆节点，不能承诺 5 秒。
4. 注意：EdgeOne Pages 在“不含中国大陆”区域的平台默认域名从中国大陆访问可能返回 401；大陆/全球含大陆区域的预览链接有时效，不可直接当稳定公开网址。

### 准备备案
1. 注册或登录腾讯云并完成个人实名认证。
2. 准备可备案的云服务资源、域名及当地要求的个人资料。是否需付费购买服务器或符合条件的其他资源，以备案控制台最新要求为准。
3. 按腾讯云备案指引完成 ICP 备案。未经备案不要启用中国大陆 CDN 加速。
4. 获批后，在 EdgeOne Pages 创建项目：选择“导入 Git 仓库”、授权 GitHub、选择本仓库及已验证的生产分支。
5. 本站是静态 HTML，无需 Node 构建。按平台静态站点配置根目录和产物目录；部署前核对所有文件限制。
6. 选择“中国大陆可用区”，绑定已备案的自有域名，按控制台给出的 CNAME 进行 DNS 解析，启用 HTTPS。
7. HTTPS 和域名访问正常后，保留原 github.io 网址为备用；无需关闭旧站。

## 部署阻塞项（优先检查）
- EdgeOne Pages 单个文件上限 25 MiB；如果任意视频/高清素材超限，要拆分/压缩视频或把大文件改成按需对象存储链接，不能直接导入。
- 项目文件数上限 20,000；单账号 Pages 部署存储总限额可能为 5 GiB（具体以平台控制台/最新说明为准）。
- 当前仓库体积约 626 MiB，含大量图库素材。建议优先剔除从网站未引用的版本/备份，以及将“大图原图打开”与“网页预览小图”分离。
- 平台自带的临时域名不能用来代替长期可靠的国内公开域名。
- 用户手动点击播放视频才加载 MP4；作品图片保持“先缩略图、滚动到附近才加载”的原则。

## 国内测速与通过标准
测试设备 / 网络至少：苏州电信宽带、移动 5G、联通 5G；首次访问无缓存 + 第二次访问有缓存各测 3 次。
记录：
- DNS、TCP/TLS 连接、TTFB（首字节）、FCP（首次内容绘制）、LCP（最大内容绘制）、总传输量、失败资源。
- 首屏目标：常见 4G/5G/宽带下，LCP 尽量 <= 5 秒且导航可用；长作品图库按需加载，不以 5 秒下载 1,000+ 张原图为目标。
- 分别验证首页、45 个项目分类与项目详情、照片放大、手动视频播放、跳过开场、音乐开关、主题切换。
- 部署失败或首屏明显回退时，不要切换正式域名 DNS，维持 GitHub Pages。
